# Berth artwork

`berth.svg` is the original supplied by tobagin from Downloads on 2026-10-16.
Its copyright and AGPL-3.0-only notice are retained in the SVG. `berth.png` is a
256-pixel rasterization of the same artwork under the same license, generated by:

```sh
rsvg-convert -w 256 -h 256 packaging/berth.svg -o packaging/berth.png
```

The runtime loads `org.openpak.berth.png` beside the executable; both image
formats are distributed separately from the emulator binary. The desktop entry
uses the `org.openpak.berth` icon name. Installation into a desktop icon theme is
not performed by the build wrapper.
